# OTC heating curve table (K curves, 1 °C steps)

Flow-temperature setpoint (°C) that the controller targets for each outdoor temperature and K value set in **P154** (Zone 1; P155/P156 for Zones 2/3, range 0.2–6.0, 0 = Off).

**Formula (matches every value in the table up to 70 °C, i.e. the whole useful range):** `Flow setpoint = 20 + K × (20 − T_outdoor)`. At 20 °C outdoor every curve gives 20 °C. Only the steep curves (K ≥ 2.5) deviate above that, flattening and topping out at 85 °C, but the heat pump itself is limited to 75 °C max (P02 range) and P115 = 83 °C max flow.

**Manual guidance (user manual §4.9):** K ≥ 1 for radiators; **K ≤ 0.8 for underfloor heating**, and never pick a curve that can produce more than 55 °C on an underfloor circuit. OTC works in heating mode only; activate by setting P154 ≠ Off and selecting “OTC” in the Operating modes menu. A separate OTC outdoor sensor (P153) is recommended over the unit’s own C02 sensor.

Quick reference for underfloor curves: at −10 °C outdoor → K0.3 = 29, K0.4 = 32, K0.5 = 35, K0.6 = 38, K0.7 = 41, K0.8 = 44 °C. At 0 °C → K0.3 = 26, K0.4 = 28, K0.5 = 30, K0.6 = 32, K0.7 = 34, K0.8 = 36 °C.
